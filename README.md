## 功能

### 已完成

- 基于 Go 的高性能服务端，TLS 加密通信
- 客户端心跳检测、密钥协商与超时自动剔除
- C 语言客户端框架，核心通信链路可用
- Web 管理面板基础骨架（登录页 + 控制台 UI）

### 待协作补齐

- 多协议监听器架构
- 插件化模块系统
- 控制台功能逻辑对接
- 客户端功能实现（Shell 交互、文件传输、进程管理、持久化等）
- 客户端平台扩展（Linux / macOS）
